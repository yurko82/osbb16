## 1. Передісторія та перезапуск проєкту
- **Попередня версія (v1.0):** Статичний прототип на Vanilla JS / HTML / localStorage (перенесено до каталогу `legacy_v1/`).
- **Вимога користувача:** Повний рефакторинг та створення виробничої системи на **PHP 8.2+**, **MySQL**, з **Telegram-ботом** та розміщенням на власному хостингу.

---

## 2. Архітектура v2.0
Створено повноцінний легковаговий MVC-фреймворк без надлишкових залежностей:

- **Ядро (`src/Core/`):**
  - `Router.php` — обробка маршрутів GET/POST, URL-параметрів, middleware авторизації та ролей.
  - `Database.php` — Singleton PDO з автоматичним підключенням до MySQL, UTF-8mb4, обробкою помилок.
  - `Auth.php` — сесії, перевірка ролей (`admin`, `accountant`, `master`, `resident`), хешування bcrypt.
  - `Csrf.php` — генерація та верифікація CSRF-токенів для форм.
  - `Request.php` / `Response.php` / `View.php` — сервісні класи HTTP та рендерингу шаблонів.
  
- **Контролери (`src/Controllers/`):**
  - `AuthController.php` — авторизація, вихід із системи, розмежування перенаправлень за ролями.
  - `DashboardController.php` — кабінет мешканця (баланс, лічильники, квитанції, заявки).
  - `AdminController.php` — адмін-панель (реєстр квартир, баланси, заявки, новини).
  - `BillingController.php` — генерація квитків, розрахунок площ/лічильників, QR-код за стандартом НБУ.
  - `MetersController.php` — подача та історія показників лічильників (вода, світло, тепло).
  - `RequestsController.php` — диспетчерська заявок на ремонт / виклик майстра.
  - `MasterController.php` — мобільний кабінет для чергового техніка/сантехніка.
  
- **База даних (`database/`):**
  - `schema.sql` — повна структура таблиць: `buildings`, `apartments`, `users`, `services`, `tariffs`, `meters`, `meter_readings`, `invoices`, `invoice_items`, `payments`, `service_requests`, `announcements`, `polls`, `poll_options`, `poll_votes`.
  - `seed.sql` — базові дані будинку, квартир, діючих тарифів та користувачів.

- **Telegram-бот (`bot/`):**
  - `worker.php` — демон для Long-polling (розробка/тести).
  - Підтримка Webhook для продакшну з інтеграцією Telegram WebApp.

## 4. Поточний статус тестування
- **Вирішена проблема з авторизацією:**
  - *Симптом:* При спробі входу форму повертало з помилкою «Невірний email або пароль».
  - *Причина:* У файлі `seed.sql` для користувача `admin@mydom.ua` було записано некоректний тестовий хеш, а для мешканців був згенерований хеш слова `password`, а не `123456`.
  - *Виправлення:* Згенеровано актуальні bcrypt-хеші:
    - `admin123` -> `$2y$10$wSD0t18X7/gp4bGF.DfyJ.SpXKMthaEfkbBF6NfUON9zCd3EpFveG`
    - `123456` -> `$2y$10$MjfkIRcm8pZ34OXh1OPFBe75Jm06a/IaibXWTIzkcDy4eMnxFp6gW`
    - Базу даних на сервері оновлено.
- **Результат верифікації:**
  - Вхід Адміністратора (`admin@mydom.ua` / `admin123`) — успішно (перенаправлення в `/admin`).
  - Вхід Мешканця (`ivan@test.ua` / `123456`) — успішно (перенаправлення в `/dashboard`).
