# 🏢 МійДім ОСББ — Веб-портал та Telegram-бот

Повноцінна сучасна система для автоматизації управління багатоквартирним будинком (ОСББ).
Стек: **PHP 8.2+**, **MySQL / MariaDB**, **Tailwind CSS**, **Telegram Bot (Long-polling + WebApp)**.

---

## 🌟 Основні можливості

- **Особистий кабінет мешканця:**
  - Огляд балансу, поточних заборгованостей та історії нарахувань.
  - Подача показників лічильників води, тепла та електроенергії з автоматичним розрахунком споживання.
  - Деталізовані рахунки з формуванням **платіжного QR-коду за офіційним стандартом НБУ** (швидка сплата за IBAN через Monobank, Приват24, Sense).
  - Створення заявок на ремонт та виклик майстра з відстеженням статусу.
  - Участь в опитуваннях мешканців будинку.
  - Зв'язування акаунта з Telegram-ботом в один клік.

- **Панель голови ОСББ та Бухгалтера (`/admin`):**
  - Реєстр квартир з площами, мешканцями та поточним сальдо.
  - **Автоматичний білінг-двигун:** генерація щомісячних квитанцій (площа × тариф + обсяг лічильників × тариф).
  - Управління діючими тарифами на послуги.
  - Диспетчерська заявок: призначення майстрів, зміна статусів, звіти.
  - Публікація новин з опцією **миттєвої масової розсилки сповіщень у Telegram-бот**.

- **Кабінет техніка / майстра (`/master`):**
  - Спеціальний інтерфейс для перегляду призначених заявок, взяття в роботу та додавання звітів про виконання.

- **Гібридний Telegram-бот:**
  - Команди `/balance`, `/meters`, `/requests`, `/news`.
  - **Telegram WebApp:** відкриття повноцінного адаптивного кабінету прямо у вікні месенджера.
  - Підтримка як **Long Polling** (`php bot/worker.php`) для розробки без публічного IP/SSL, так і **Webhook** для хостингу.

## 🚀 Швидкий запуск

### 1. Імпорт бази даних MySQL
Створіть базу даних (наприклад, `osbb_db`) у MySQL/MariaDB та імпортуйте файли:
```bash
mysql -u root -p osbb_db < database/schema.sql
mysql -u root -p osbb_db < database/seed.sql
```

### 2. Налаштування середовища (.env)
Скопіюйте `.env.example` у `.env` (або відредагуйте вже створений `.env`):
```ini
DB_HOST=127.0.0.1
DB_DATABASE=osbb_db
DB_USERNAME=root
DB_PASSWORD=your_password

# Реквізити вашого ОСББ для генерації платіжок та QR-коду НБУ
OSBB_NAME="ОСББ Затишний Дім"
OSBB_EDRPOU="38947211"
OSBB_IBAN="UA213223130000026007233566123"

# Токен вашого Telegram-бота від @BotFather
TELEGRAM_BOT_TOKEN="123456789:ABCdefGHIjklmnoPQRstuVWXyz"
TELEGRAM_BOT_USERNAME="MyDomOsbbBot"
```

### 3. Запуск веб-сайту
У папці проєкту запустіть локальний сервер PHP:
```bash
php -S localhost:8000 -t public
```
Відкрийте у браузері: `http://localhost:8000`

### 4. Запуск Telegram-бота (Long Polling)
В окремому вікні термінала запустіть воркер:
```bash
php bot/worker.php
```

## 💳 Інтеграція QR-коду за стандартом НБУ

Система автоматично формує стандартизований рядок `BCD 002` Національного банку України, що містить:
- Номер рахунку IBAN ОСББ
- Код ЄДРПОУ
- Назву організації
- Точну суму до сплати (з урахуванням попередніх переплат або боргів)
- Призначення платежу з номером особового рахунку та квартири

Мешканцю достатньо просканувати QR-код прямо з екрана монітора або в Telegram WebApp, і банківський додаток миттєво відкриє форму платежу з повністю заповненими полями.
